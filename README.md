## 💻 Local Installation

1. Clone the repository
```bash
git clone https://github.com/Rafiklatrikdu69/portfolio-nuxt.git
```

2. Install dependencies
```bash
cd portfolio-nuxt
npm install
```

3. Launch development server
```bash
npm run dev
```
